# Go — Pointers

> Part of **[[Go MOC]]**. [[Go - Strings|← Strings]]  ·  [[Go - Control Structures|Control Structures →]]

### Pointers
- Any data structure can be a pointer
- Calculations not supported on pointers. 
- & gives reference to pointer of a variable
- * before a datatype specifies it as a pointer ex ; `*int, *float`
- The size of pointer is 4 bytes on 32-bit machines, 8 bytes on 64 bit machines.
- `var p *int = nil // Making a nil pointer`
